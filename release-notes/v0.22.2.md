## Badge Blur 0.22.2 source release

Badge Blur 0.22.2 improves recovery of conspicuous close-up credentials while
keeping the normal torso-gated detection path conservative. It also fixes blur
coverage when an editable mask reaches the physical edge of a photo.

### What changed

- Retain close-up people that occupy nearly the full frame.
- Recover classifier-confirmed large, low-hanging, and edge-cropped badges
  through scale-aware contextual checks.
- Preserve stricter torso checks for ordinary detections so the existing
  reviewed production benchmark does not gain false masks.
- Extend feathered blur beyond the canvas before cropping it back, preventing
  visible detail from leaking through the final edge pixels.

### Validation

- All 23 deterministic tests passed.
- The five-image demo production path found all 11 reviewed badges with no
  false masks.
- The frozen 18-photo benchmark remained at 75.6% recall and 89.5% precision.
- The production build and packaged Electron review smoke passed locally.

This is a source-install release delivered by the main-branch macOS bootstrap
script. The downloadable macOS and Windows installers remain at 0.22.1 until
this source build has completed hands-on testing.
