## Badge Blur 0.22.0

Badge Blur 0.22.0 makes large-batch review faster, clearer, and more
responsive while keeping all image processing local.

### Review improvements

- Adds remembered **Fit in window** and page-expanding **Fill width** viewing
  modes, with the whole review document scrolling around the photo.
- Keeps ordinary mouse-wheel and trackpad scrolling active while the pointer
  is over the photo; Command/Control-scroll remains dedicated to zoom.
- Keeps fitted photos centered in the viewer and uses one fixed, non-repeating
  page gradient at every document height.
- Centers the first photo immediately after **Start batch**, including the
  initial hidden-to-visible review transition.
- Adds cursor-centered zoom controls, Command/Control-scroll zoom,
  double-click zoom, and Space-drag panning.
- Prepares the redacted After preview during processing so unchanged photos
  compare immediately.
- Adds a per-badge blur-strength override that persists in the image's run
  data.
- Adds a keyboard-operable **Badge N of N** inspector with previous/next,
  blur, reset, and remove controls.
- Separates badge editing from clearer **Re-detect image**, **Save only**, and
  **Save, review & next** actions. Review confirmation now persists the latest
  image/run state and advances to the next unreviewed ready photo.
- Adds review progress and stronger selected-mask feedback.
- Places **Mark this image reviewed** beside the centered photo, makes the
  active filmstrip thumbnail unmistakable, and keeps the photo visible in
  short windows by allowing normal page scrolling.
- Joins the filmstrip and batch actions into one in-flow lower work rail
  without overlaying the photo.
- Allows reviewers to edit masks and save a completed image while other images
  continue processing.
- Uses a calm **All images ready for review** state with no caution icon or
  yellow warning treatment. **Attention needed** is reserved for processing
  failures and clearly implausible automatic masks; visible people and
  lanyards never imply that a badge must be present.
- Improves automatic corner fitting for colored and loose badge detections
  while retaining conservative coverage safeguards.
- Requires automatic badge detections to fall inside a detected torso. On the
  18-photo local regression this keeps 75.6% recall while improving precision
  from 81.0% to 89.5%.
- Speeds repeat auto-saves by reusing unchanged metadata and the in-memory
  redacted preview while showing queued, saving, and saved states immediately.
- Asks for the output format after source-folder selection: match the source,
  JPEG, PNG, TIFF, or WebP. The default nested output folder is unchanged;
  matching HEIC/HEIF sources continue to export as TIFF.
- Restores a live processing timer beside the progress counts and keeps the
  final total visible when the batch finishes.
- Reuses a bounded local copy of each source, decodes full-resolution pixels
  once per redaction, and processes independent mask patches concurrently.

### Reliability and release hardening

- Keeps model inference in a bounded two-worker Web Worker pool so the review
  interface remains responsive.
- Records per-image stage timings in run data and caps Auto at two workers
  based on the local four-image benchmark; four remains a manual option.
- Prevents Delete from affecting a selected badge on a non-active image.
- Adds a complete 20-test deterministic command to both installer jobs.
- Extends Electron smoke testing through review navigation, per-badge blur,
  scoped deletion, Fill width scrolling, source caching, JPEG save, and the
  restored timer.
- Updates build-only transitive dependencies to resolve the current npm audit
  findings.

Human review remains required. Badge Blur is a local first-pass redaction
assistant, not an unattended compliance control.
