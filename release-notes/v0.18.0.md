## Badge Blur 0.18.0

Badge Blur is now a complete Electron desktop application. It opens in its own
window and no longer depends on Safari, Brave, Chrome, or Edge for source-folder
access and automatic batch export.

### What changed

- Bundled a controlled Chromium runtime on macOS and Windows.
- Added native desktop-window behavior and single-instance launching.
- Made Electron own the private local image service and shut it down when the
  app window closes or the user quits.
- Retained the existing local Grounding DINO, CLIP, metadata-preserving export,
  batch queue, editable quadrilaterals, and Gaussian blur workflow.
- Kept the visible renderer sandboxed with Node integration disabled and
  navigation restricted to the private local app.
- Replaced the legacy browser launchers with Electron Forge DMG/ZIP packaging
  for Apple silicon and a per-user Squirrel.Windows installer for Windows x64.
- Added packaged Electron capability tests for folder selection, local-only
  execution, and clean service shutdown.

### Downloads

- **Mac Apple Silicon:** use the DMG for a conventional drag-to-Applications
  installation, or use the ZIP for immediate testing.
- **Windows x64:** run the Setup EXE. It installs for the current user and can
  be removed under **Settings > Apps > Installed apps**.
- SHA-256 checksum files accompany every installer archive.

### Unsigned-build notice

These test builds are not Developer ID/notarized on macOS and are not
Authenticode-signed on Windows. Electron fixes browser compatibility but does
not bypass Gatekeeper, SmartScreen, or organization-managed application
controls. Managed computers may require IT approval or managed deployment.

### Detection qualification

The frozen 18-image evaluation remains at 75.6% recall and 81.0% precision.
Badge Blur remains an assisted-review tool: users must review every proposed
mask and exported image before distribution.
