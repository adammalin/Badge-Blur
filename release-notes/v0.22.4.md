## Badge Blur 0.22.4 installer release

Badge Blur 0.22.4 brings the detection, mask-placement, export-folder, and
guided review improvements tested in the recent source releases into new Mac
and Windows installers. It is the first packaged release since 0.22.1.

### What changed

- Recover classifier-confirmed large, low-hanging, and edge-cropped badges
  while retaining conservative torso checks for ordinary detections.
- Keep blur fully opaque through the physical edge of a photo when a mask
  extends beyond the canvas.
- Improve corner placement on faint and rotated credentials using a temporary
  analysis-only contrast pass; original and exported image contrast is never
  changed.
- Keep long mask labels compact and inside the visible photo.
- Finish processing with a clear **Review photos** handoff, start review at
  image 1, turn the final approval into **Export all**, and celebrate a
  successful export with silent confetti.
- Open the exact completed export run in Finder instead of presenting an
  unrelated Desktop folder chooser.
- Add a soft edge-only processing pulse and restrained guidance on the next
  actionable **Start batch** or **Save, review & next** control.
- Respect reduced-motion preferences by keeping guidance static.
- Deny Electron renderer requests outside the private loopback service.

### Validation

- All 25 deterministic tests passed.
- The five-image demo production path found all 11 reviewed badges, fitted all
  11 masks, and produced no false masks.
- The frozen 18-photo benchmark remained at 75.6% recall and 89.5% precision,
  with 35 of 38 masks safely corner-fitted.
- The production build and complete Electron workflow smoke passed both from
  source and from the packaged Apple-silicon application.
- Desktop smoke coverage verified the setup guidance, review guidance,
  processing edge effect, and cleanup after processing.
- The Mac application passed strict deep signature verification, and the DMG
  and ZIP passed their published SHA-256 checksums.
- Release automation independently builds and tests the Mac and Windows
  packages on their matching operating systems before publishing the release.

The release includes an Apple-silicon Mac DMG and ZIP, a Windows x64 per-user
installer, and a SHA-256 checksum for every download. These packages are not
Developer ID, Apple-notarized, or Windows code-signed, so operating-system
security approval may still be required. The main-branch macOS source
bootstrap installs the same 0.22.4 application code.
