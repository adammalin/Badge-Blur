## Badge Blur 0.22.4 source release

Badge Blur 0.22.4 adds restrained visual guidance that helps users move from
setup through processing and review without changing detection or export
quality.

### What changed

- Add a soft, pulsing green glow at the outer edge of the screen while batch
  detection is active.
- Gently glow and occasionally bounce **Start batch** once the source folder
  and output format make it actionable.
- Apply the same guidance to **Save, review & next** during the review pass.
- Stop each effect as soon as its action is no longer relevant.
- Respect reduced-motion preferences by retaining only static emphasis.

### Validation

- All 25 deterministic tests passed.
- The production build and complete Electron workflow smoke passed locally.
- Desktop smoke coverage verified the setup guidance, review guidance,
  processing edge effect, and cleanup after processing.

This is a source-install release delivered by the main-branch macOS bootstrap
script. The downloadable macOS and Windows installers remain at 0.22.1 until
new installer builds are explicitly requested and qualified.
