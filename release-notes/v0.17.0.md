## Badge Blur 0.17.0

This release makes the packaged macOS and Windows apps shut down and restart
cleanly.

### What changed

- Added a visible **Quit Badge Blur** button that stops the private local
  service and releases its port.
- Added per-launch shutdown authorization, launcher monitoring, PID ownership
  tracking, and conservative stale-process cleanup.
- Updated the Windows uninstaller to stop and verify the local service before
  removing the installation.
- Added cross-platform lifecycle regression tests for shutdown, relaunch,
  signal handling, invalid authorization, and orphan cleanup.
- Kept installer builds limited to manual runs and version tags; ordinary
  pushes do not run the large installer workflow.

### Downloads

- **Mac Apple Silicon:** use the DMG for a conventional drag-to-Applications
  install, or the ZIP for immediate testing.
- **Windows x64:** run the Setup EXE. Badge Blur appears in the Start menu and
  Windows Installed Apps and can be removed with the included uninstaller.
- SHA-256 files are included for each installer archive.

### Unsigned-build notice

These test builds are not Developer ID/notarized on macOS and are not
Authenticode-signed on Windows. macOS testers must use **System Settings >
Privacy & Security > Open Anyway** after the first blocked launch. Windows may
show a Microsoft Defender SmartScreen warning. Organization-managed computers
may prevent these overrides.

### Detection qualification

The frozen 18-image evaluation remains at 75.6% recall and 81.0% precision.
Badge Blur is an assisted-review tool: users must review every proposed mask
and exported image before distribution.
