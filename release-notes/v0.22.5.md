## Badge Blur 0.22.5 source release

Badge Blur 0.22.5 adds a private, interactive first-run walkthrough to help new
users move confidently from selecting photos through processing, review, and
export.

### What changed

- Guide first-time users through nine steps over the actual app controls:
  source folder, output format, advanced settings, batch start, review,
  attention guidance, export, and tutorial replay.
- Add a visible **Tutorial** control so the walkthrough can be opened again at
  any time.
- Save tutorial completion only in the desktop app's local user data. The web
  development view uses local browser storage as a fallback.
- Restore the user's original setup or review stage after the walkthrough is
  completed or skipped.
- Keep highlights aligned through stage and layout changes, including on small
  screens, and keep the tutorial card inside the visible window.
- Support Escape, left/right navigation, keyboard focus containment, dark
  appearance, and reduced-motion preferences.

### Validation

- All 28 deterministic tests passed.
- The production build and complete source Electron workflow smoke passed.
- The desktop smoke verified first-run readiness, tutorial replay, keyboard
  navigation, stage restoration, and all existing workflow capabilities.
- Every target in all nine tutorial steps was visible, its spotlight was
  aligned, and its tutorial card remained inside the viewport.

The main-branch macOS source install/update script installs Badge Blur 0.22.5.
Existing packaged Mac and Windows installers remain at 0.22.4; this source
release does not include new installer artifacts.
