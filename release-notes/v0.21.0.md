## Badge Blur 0.21.0

This release makes large-batch review more responsive and fixes the native
**Open export folder** action.

### What changed

- Keeps Start/Pause/Export and the progress bar fixed at the bottom of the
  reviewer.
- Allows filmstrip, Previous/Next, arrow-key, and Before/After navigation while
  a batch is processing; mask edits remain safely locked until processing
  finishes.
- Runs person guidance before enhanced badge filtering so off-person signs do
  not bypass negative classification.
- Retains hanging lanyard cards and large edge-cropped foreground badges that
  a strict anatomical torso boundary could miss.
- Bounds ONNX threads, yields between heavy stages, and serializes
  full-resolution redaction and metadata requests to preserve UI and loopback
  service capacity.
- Retries one transient local fetch and adds a bounded final Electron exit
  fallback after graceful private-service shutdown.
- Verifies and opens source-based run folders even when Chromium handles do not
  expose a native path.
- Selects the current-version installer artifact when older Electron Forge
  output remains on a developer machine.

### Qualification

The actual Electron UI processed and auto-saved all five demo images with two
workers in 1m 32s. The filmstrip returned `1, 2, 4, 1, 3` masks, covering all
11 expected synthetic badges with no extra masks. The fifth image remained
viewable during active processing, the fixed dock stayed attached to the
viewport, and completion returned review to image 1.

The native preload bridge opened an exact checkpoint-verified export folder
without the earlier verification error. The frozen 18-image local-photo
regression remains at 75.6% recall and 81.0% precision, so Badge Blur is still
an assisted-review tool: review every proposed mask and exported image.

### Downloads

- **Mac Apple Silicon:** use the DMG for a conventional drag-to-Applications
  installation, or the ZIP for immediate testing.
- **Windows x64:** run the Setup EXE. It installs for the current user and can
  be removed under **Settings > Apps > Installed apps**.
- SHA-256 checksum files accompany every installer archive.

### Unsigned-build notice

These test builds are not Developer ID/notarized on macOS and are not
Authenticode-signed on Windows. macOS testers must use **System Settings >
Privacy & Security > Open Anyway** after the first blocked launch. Windows may
show a Microsoft Defender SmartScreen warning, and managed computers may
require IT approval or managed deployment.
