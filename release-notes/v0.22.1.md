## Badge Blur 0.22.1

Badge Blur 0.22.1 makes correcting and re-exporting individual photos faster,
and improves detection when portrait and landscape credentials appear together
on the same person.

### Faster correction and export

- Adds **Re-export this image** to each processed photo.
- Adds **Re-export changed (N)** to save only images edited since their last
  successful export.
- Regenerates the redacted After view immediately when a visible mask or blur
  setting changes, including manually added masks.
- Reuses that full-resolution After result for saving instead of processing
  the image twice.
- Coalesces duplicate autosave and manual-save requests while showing clear
  queued, saving, and saved feedback.

### Detection improvement

- Keeps every automatic badge constrained to a detected torso.
- When one credential is already found, performs one complementary-orientation
  search for a neighboring vertical or horizontal credential.
- Accepts a wider range of legitimate portrait and landscape badge shapes
  while retaining the classifier safeguard.
- Preserves the frozen 18-photo benchmark result: 75.6% recall and 89.5%
  precision.

All image processing remains local. Human review is still required; Badge Blur
is a first-pass redaction assistant rather than an unattended compliance
control.
