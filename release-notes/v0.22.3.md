## Badge Blur 0.22.3 source release

Badge Blur 0.22.3 improves corner placement for low-contrast and rotated
credentials, clarifies the process-review-export workflow, and makes completed
export runs open directly in Finder.

### What changed

- Analyze a temporary local-contrast copy when ordinary badge edges are faint;
  the original and exported pixels remain unchanged.
- Reconcile opposite badge edges so internal card graphics do not pull the
  mask away from the outer credential, including horizontal rotated cards.
- Keep canvas mask labels compact and inside the visible photo.
- End processing with an animated green completion state and a **Review
  photos** action that starts at image 1.
- Turn the final approval action into **Export all** and celebrate a successful
  export with silent confetti.
- Open the exact macOS export run in Finder by verifying its unique run-folder
  name and saved run ID, without an unrelated Desktop chooser.
- Deny Electron renderer requests outside the private loopback service.

### Validation

- All 25 deterministic tests passed.
- The five-image demo production path found all 11 reviewed badges, fitted all
  11 masks, and produced no false masks.
- The frozen 18-photo benchmark remained at 75.6% recall and 89.5% precision,
  while safe corner fits improved to 35 of 38 masks.
- The production build and complete Electron workflow smoke passed locally,
  including processing completion, first-image review, final export, silent
  confetti, and local-only network controls. The exact Finder resolver was
  separately exercised against a real completed export.

This is a source-install release delivered by the main-branch macOS bootstrap
script. The downloadable macOS and Windows installers remain at 0.22.1 until
new installer builds are explicitly requested and qualified.
